# Furbo Mini 360° 可视化报告使用说明

## 打开报告

在 Finder 中双击同目录的 `Furbo_Mini360_可视化竞品体验报告.html`，使用 Safari、Chrome 或 Edge 打开。报告不需要联网，不需要启动服务，不依赖在线字体或外部资源。

如需移动、备份或分享，请复制整个 `Furbo_Mini360_竞品体验测评` 文件夹。HTML通过相对路径读取项目中的原始截图，不能只单独复制HTML文件。

## 如何阅读

1. 左侧固定目录跳转到对应章节；当前阅读章节会高亮。窄窗口通过“研究目录”按钮展开目录。
2. 在章节中查看完整比例的截图缩略卡；点击图片或证据编号即可放大。
3. 放大窗口支持“原始尺寸 / 适应窗口”、上一张/下一张；键盘左右箭头切换，Esc关闭。“查看原图”打开未经修改的原始PNG。
4. 截图下方展开“步骤、结论与原始位置”，可查看所属模块、实际操作、证据状态和原始路径。
5. “证据索引”支持按编号、关键词和章节筛选；表格在窄窗口内横向滚动。
6. 左下方“打印 / 保存PDF”调用浏览器打印。HTML为主要交互交付物，打印效果随浏览器分页有所差异。

- 原始资料8份Markdown；阶段1共39张PNG、38组证据；阶段0环境附图2张，原始PNG总数41张。
- E12-V为完整手机视口派生图，E12-O为对应原始桌面文件。二者保留原文件名和关系，不计为两次独立验证。
- 报告有13个目录，其中项目概览、证据索引不计入研究章节。其余11章中，产品基础档案、App信息架构、首页体验共3章完成了本阶段记录。
- 阶段1原始四份文档均已完成交付；硬件能力清单已成文，但硬件执行研究仍未完成，因此硬件章节只标“部分记录”。
- “已通过实际操作确认”只限对应的页面进入、滚动、切换和返回。AI准确率、硬件执行、订阅权益不能据入口或蓝色开关推断。
- 设备离线为用户提供的环境事实。历史在线图不代表当前在线；镜像锁定不属于Furbo产品问题。
- 本报告没有新增官方或第三方能力/价格资料。原文“官方信息待核验”“暂时无法确认”等语义统一保留为待验证。

## 如何持续更新

1. 先在原研究目录追加经过核验的研究记录与截图，在原始证据索引登记新的E编号。不要重用旧编号或改动旧图。
2. 在本目录 `报告数据.json` 中更新对应章节范围、事实及状态。新增证据应补齐section、steps、finding、record，并与原索引编号一致。
3. 在安装Python 3.9或更新版本的Mac上，在本目录运行 `python3 生成报告.py`。生成器会重新读取原研究文档、PNG数量和证据索引，生成HTML、总报告、派生证据索引和分类清单。
4. 重新打开HTML，检查新图、原图路径、证据编号和状态；如原始资料校验发生变化，确认是经过审核的追加或改动。质量检查记录需随版本重新更新，不能沿用旧结果。
5. 维护时以 `报告数据.json` 为分析内容源，避免只编辑生成后的HTML而导致Markdown不同步。生成器只覆盖本目录中的派生成果，不写入原研究文档或原始截图。

首次生成的原始资料清单为本轮校验基线。后续生成会比较上次清单的文件与哈希，并扫描新追加材料；修改已有原图会导致完整性检查失败。

## 当前研究边界

设备离线，实时预览按用户要求暂停。主账号/共享绑定身份、会员价格与权益、设备切换路径、实际硬件执行、AI准确率及通知送达均仍待核验。

问题卡片中的用户影响属于分析推测；严重程度尚未定级。创新机会均为待验证假设，不代表用户需求或效果已成立。

本报告包含真实账号及家庭画面截图，原图保持原样。对外分享前请自行审查接收范围；如需脱敏，应另存副本并保留与原证据的对应关系。

本次整理完成后等待用户审核，不自动执行后续实机测评。
