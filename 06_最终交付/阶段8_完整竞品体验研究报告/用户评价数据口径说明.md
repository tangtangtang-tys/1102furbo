# 用户评价数据口径说明

截至2026-11-16，本阶段形成两层数据：

1. **App级公开聚合指标**：Apple Search/Lookup API返回当前 Furbo App（App ID 999707163）平均评分 **4.78465/5**、评分数 **5,591**。该数据代表App整体公开口碑信号，不代表Mini 360°硬件评分，也不进入硬件主题、情感或痛点统计。
2. **逐条用户评论样本**：仍为0。Apple RSS接口返回HTTP 200但没有评论entry；Reddit搜索超时，Trustpilot返回403，Amazon检索页未形成可去重、可确认型号的评论记录。

因此：

- `app_store_aggregate.csv` 保存App级聚合指标；`apple_lookup_999707163_20261116.json` 保存本次Lookup响应快照。
- `user_reviews_raw.csv`、`user_reviews_cleaned.csv`、`user_reviews_coded.csv` 仍保持统一字段但数据行数为0。
- 不生成1—5星分布、情绪占比、主题提及率、痛点TOP10或时间趋势的虚假数字。
- App评分和评分数不能下沉为Mini 360°硬件评分，也不能证明用户购买、留存、续费或故障率。
- 阶段7.2和本地实测仍然可以支持体验判断，但不被表述为用户评价统计。
